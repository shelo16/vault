Folders & nesting

Use the + Folder button in the New Entry popup to create nested folders. Any depth is supported:

gmailUngrouped entry (no folder)
google / gmail"gmail" inside folder "google"
acme / prod / db"db" inside "prod" inside "acme"
acme / prod / websibling of db under acme/prod

Right-click any folder in the sidebar to Rename, Duplicate or Delete it.
Click a folder name to filter the main view to that folder. Click its ▶ arrow to expand subfolders.

Common field names

urlWebsite or API endpoint URL
username / user / emailLogin identity
password / pass / pwdPassword secret
token / api_key / api-keyAPI key or bearer token secret
secret / privateAny secret value secret
hostHostname or IP address
portPort number
db / databaseDatabase name or connection string
sshSSH command, e.g. ssh user@10.0.0.1
note / notesFreeform notes or runbook steps
cmd / commandBuild command or CLI invocation

Fields matching pass, pwd, secret, token, api_key or private are automatically marked secret.
